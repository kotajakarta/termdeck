# TermDeck Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplikasi desktop mirip Termius: terminal SSH multi-server, multi-tab, dengan "proyek" (server + path) yang bisa dibuka sekali klik.

**Architecture:** Backend Python (FastAPI + asyncssh) berjalan di thread lokal `127.0.0.1:<port acak>` dengan token acak; frontend React (Vite + xterm.js) di-build menjadi static file yang disajikan backend; jendela native dibuka oleh pywebview (WebView2 di Windows, Qt WebEngine di Linux). Terminal = WebSocket ↔ channel PTY asyncssh. Data di SQLite, kredensial terenkripsi Fernet.

**Tech Stack:** Python 3.10+, FastAPI, uvicorn, asyncssh, cryptography, platformdirs, pywebview; React 18 + TypeScript + Vite, @xterm/xterm, @xterm/addon-fit, @xterm/addon-web-links.

**Spec:** Percakapan 2026-10-16 (ringkasan di bawah).

> **Perubahan 2026-10-16 (permintaan user):** GUI tidak lagi memakai pywebview. Aplikasi disajikan di browser pada `http://localhost:9095` (`termdeck.py`). Token disisipkan ke `index.html` (meta tag), Host header dibatasi `localhost`/`127.0.0.1`, Origin WebSocket dicek. Shortcut pindah ke `Alt+P/T/W` dan `Alt+Shift+←/→` karena browser memakai kombinasi `Ctrl`. Bagian di bawah yang menyebut pywebview/desktop window sudah tidak berlaku.

> **Perubahan 2026-10-16 (2):** Seluruh database dienkripsi dengan SQLCipher (`termdeck.vault`), kunci = scrypt(PIN, salt `vault.key`). Login PIN wajib (PIN awal `7821724`, env `TERMDECK_PIN`), sesi per tab, throttle 5 percobaan, kunci & ganti PIN di UI, migrasi otomatis dari `termdeck.db` lama. Fernet field-level hanya dipakai untuk migrasi.

> **Perubahan 2026-10-16 (3):** Dukungan Windows dihapus atas permintaan user (run.bat, venv Windows). Hanya Linux (termasuk WSL) via `run.sh`.

## Requirement (dari user)

1. Tambah server via kredensial SSH (password atau private key).
2. Simpan path untuk akses cepat ("proyek" = server + path; klik → tab baru, login, `cd` ke path).
3. Sidebar: info server/node + path tersimpan.
4. Jalan di Windows & Linux, **dibuka sebagai aplikasi, bukan lewat browser**.
5. Banyak tab terbuka sekaligus, pindah antar proyek cepat.

## Rekomendasi tambahan (keputusan builder)

- Enkripsi kredensial at-rest (Fernet, key file di data dir, permission 600).
- Verifikasi host key TOFU sebelum auth; host key berubah → koneksi ditolak, ada tombol reset.
- Info node live di sidebar: OS, uptime, load, CPU core, RAM, disk `/`.
- Command palette `Ctrl+Shift+P` untuk lompat ke proyek/server (`Ctrl+K` bentrok dengan kill-line bash).
- Snippets: perintah tersimpan, kirim ke tab aktif sekali klik.
- Path picker: browse direktori remote via SFTP (fallback `ls` bila SFTP dimatikan) saat menyimpan path.
- Startup command per proyek (mis. `source venv/bin/activate`).
- Grup server + warna penanda; satu koneksi SSH dipakai bersama oleh banyak tab ke server yang sama.
- Tombol reconnect pada tab yang terputus.

## Global Constraints

- Backend hanya bind `127.0.0.1`; setiap request API & WS wajib token (`X-Token` header / `token` query).
- Python ≥ 3.10, tanpa dependency C-build khusus selain wheel resmi.
- Data dir: `platformdirs.user_data_dir("TermDeck")`, override env `TERMDECK_DATA_DIR`.
- Secret (password, private key, passphrase) tidak pernah dikembalikan oleh API (hanya flag `has_secret`).
- TypeScript tanpa `any`; `npx tsc --noEmit` bersih.

## Review Focus

1. Host key server berubah → koneksi ditolak sebelum password dikirim, pesan jelas (test: `test_hostkey_mismatch_rejected`).
2. Path dengan spasi/kutip → `cd` tetap benar (test: `test_build_cd_command_quotes`).
3. Output UTF-8 terpotong di tengah karakter → tidak rusak (output dikirim sebagai bytes, xterm decode).
4. Update server tanpa mengisi password → password lama tetap (test: `test_update_keeps_secret`).
5. Hapus server → bookmark ikut terhapus (test: `test_delete_server_cascades`).

### Task 1: Storage + crypto

**Files:** `backend/app/{config,crypto,db,schemas}.py`, `backend/tests/test_db.py`

**Produces:**
- `SecretBox(key_path: Path)`: `.encrypt(str|None) -> str|None`, `.decrypt(str|None) -> str|None`
- `Store(db_path: Path, box: SecretBox)`: `list_servers() -> list[ServerOut]`, `get_server(id) -> ServerOut|None`, `get_server_secrets(id) -> ServerSecrets|None`, `create_server(ServerIn) -> ServerOut`, `update_server(id, ServerIn) -> ServerOut|None`, `delete_server(id) -> bool`, `set_host_key(id, key: str|None)`; sama untuk bookmark (`list_bookmarks(server_id: int|None)`, `create_bookmark`, `update_bookmark`, `delete_bookmark`) dan snippet.
- `ServerIn`: name, host, port=22, username, auth_type `"password"|"key"`, password?, private_key?, passphrase?, group_name="", color="".

Tests: `test_secret_roundtrip`, `test_create_and_list_server_hides_secret`, `test_update_keeps_secret`, `test_delete_server_cascades`, `test_secret_stored_encrypted` (kolom sqlite ≠ plaintext).

### Task 2: SSH layer

**Files:** `backend/app/ssh.py`, `backend/tests/test_ssh.py`

**Produces:**
- `build_cd_command(path: str, startup: str|None) -> str` → `cd -- '<path>' && clear` (+ `&& <startup>`), quoting via `shlex.quote`; `~` / `~/x` tetap diekspansi.
- `parse_stats(text: str) -> dict` dari output skrip stats bermarker.
- `ConnectionPool(store)`: `async get(server_id) -> SSHClientConnection`, `async release(server_id)`, `async close_all()`, `async stats(id)`, `async listdir(id, path) -> list[DirEntry]`. Host key: `known_hosts=lambda *_: ([], [], [])` + `validate_host_public_key` (TOFU simpan ke store; mismatch → `HostKeyMismatch`).

Tests (server asyncssh in-process): `test_build_cd_command_quotes`, `test_parse_stats`, `test_tofu_stores_host_key`, `test_hostkey_mismatch_rejected`, `test_listdir`.

### Task 3: HTTP API + WebSocket terminal

**Files:** `backend/app/{api,main}.py`, `backend/tests/test_api.py`

REST di `/api`: `servers` (GET/POST), `servers/{id}` (PUT/DELETE), `servers/{id}/stats`, `servers/{id}/ls?path=`, `servers/{id}/reset-hostkey` (POST), `servers/test` (POST ServerIn), `bookmarks` (GET `?server_id`, POST), `bookmarks/{id}` (PUT/DELETE), `snippets` (GET/POST), `snippets/{id}` (PUT/DELETE). WS `/ws/terminal?token&server_id&bookmark_id&cols&rows`: client kirim JSON `{type:"input",data}` / `{type:"resize",cols,rows}`; server kirim frame binary (output) dan text JSON `{type:"status"|"error"|"exit",...}`. Static `index.html` + assets di `/`.

Tests: `test_requires_token`, `test_server_crud_via_api`, `test_bookmark_crud_via_api`.

### Task 4: Frontend

**Files:** `frontend/src/{types,api,App}.tsx?`, `components/{Sidebar,ServerForm,BookmarkForm,PathPicker,TerminalView,TabBar,ServerInfo,CommandPalette,Snippets,Modal}.tsx`, `styles.css`

Tab tetap ter-mount (sembunyi via CSS) agar sesi tidak putus saat pindah tab. Verifikasi: `npx tsc --noEmit`, `npm run build`.

### Task 5: Desktop launcher + docs

**Files:** `desktop.py`, `run.sh`, `run.bat`, `README.md`

`desktop.py`: port bebas, token `secrets.token_urlsafe`, uvicorn di thread, tunggu siap, `webview.create_window("TermDeck", url, width=1400, height=880)`; `--browser` untuk debug. Verifikasi: launch di WSLg, smoke test API + WS ke sshd lokal/asyncssh test server.
